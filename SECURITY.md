# Security

**Found a security problem?** Please tell me privately: use **"Report a vulnerability"** on this repository's Security tab.
I'll reply within 14 days.

- Only the newest version gets fixes. Updates install themselves.
- I'll give at least 12 months' notice before updates stop. If they stop, the app keeps working and your files stay yours.
- If I learn a security hole is being used, I'll fix it, release, and tell users the same week.
- **If there's no release and no reply for 12 months, treat the app as unsupported.** To remove it: Windows Settings > Apps >
  Installed apps > Recanic - Screen Recorder > Uninstall. Its settings are kept in %APPDATA%\SR; your recordings stay where
  they were saved and are never deleted by uninstalling.
- The app is built following a written set of checks (the Safety Net).
